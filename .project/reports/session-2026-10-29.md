## Décisions

1. **Layout global** : `src/shell/pages/bac-page.ts` (lignes 180-186) fournit déjà le
   wrapping de contenu → les BACs n'ajoutent plus de wrapper `max-w-* mx-auto` redondant
   (Booking, Portfolio, Spaces).
2. **Convention header** : `bac-page-header` avec `<h1>` (1.5rem bold) +
   `bac-page-subtitle`, icône Material Symbols dans un tile `w-10 h-10 bg-primary/25`.
3. **Convention tabs** : `bac-tab-btn` (+ `.active`) remplace les ternaires de classes inline.
4. **Artefacts Solara sponsorisés** : l'identité éditoriale « sponsorisé » (couleur
   warning/amber) est conservée comme signal métier, mais toutes les interactions UI
   (hover, toasts, CTA) utilisent les tokens sémantiques.
5. **Conformité `@mosaix/theme`** : les tokens `--color-*` sont injectés par
   `theme-bridge.ts` à partir des variables `--mx-*` compilées depuis `themes/*.json`.
   Les classes sémantiques consommées par les vues suivent donc le thème actif à chaud ;
   aucune valeur hexadécimale n'est codée en dur dans les vues.
