### 2. Fix test HTTP BAC access

**Commit :** `c330dd9` — `fix(tests): allow in-memory settings store for HTTP integration tests`

**Problème :** Le test `bac-access.http.test.ts` échouait avec un timeout de 150s dans `beforeAll`. Le serveur plante au boot car `MOSAIX_DEMO_USERS=false` active `InMemoryGuard.reportFallback()` sur `PlatformSettingsService`, qui utilise par défaut `InMemoryPlatformSettingsStore`.

**Solution :** Ajout de `ALLOW_IN_MEMORY_IN_PRODUCTION=true` dans les env du test. Le test cible le routage HTTP et l'accès BAC, pas la persistance des settings.

**Validation :**
- `npx vitest run tests/http/bac-access.http.test.ts` → 14/14 passés (32s)
- `pnpm test` (full suite) → 202 fichiers, 1167 tests passants
