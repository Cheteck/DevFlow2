# MosaiX Template Theme (_template)

This is the reference template theme used for validation, testing, and scaffolding new themes in MosaiX.

## Structure
- `theme.json`: Manifest declaring slots, layouts, tokens reference, and asset presets.
- `tokens/`: Base and dark design tokens (generic keys only, no business logic).
- `settings.schema.json`: Tenant-customizable options schema.
- `mails/`: Generic email shell layout (`layout.html`).
- `locales/`: Localization files (`fr.json`).
- `rtl.css`: RTL chrome styles.
- `preview.png`: Visual preview graphic (required by CI).
