# @mosaix/ports-database

Database port for the MosaiX platform. Decouples schema access and migration
locking from the concrete engine (PostgreSQL, SQLite Node, SQLite WASM/OPFS).

Aligned with [ADR-0006](../../../.project/decisions/ADR-0006-database-port-migration-engine.md).

## Exports

```typescript
export interface DatabasePort {
  readonly capabilities: DatabaseCapabilities;
  execute(sql: string, params?: readonly unknown[]): Promise<number>;
  query<T>(sql: string, params?: readonly unknown[]): Promise<T[]>;
  acquireMigrationLock(): Promise<MigrationLock>;
}

export interface DatabaseCapabilities {
  readonly dialect: Dialect; // "postgres" | "sqlite"
  readonly transactions: boolean;
  readonly lock: LockCapabilities;
}

export interface LockCapabilities {
  readonly distributed: boolean;
  readonly processSafe: boolean;
  readonly runtimeSafe: boolean;
}

export interface MigrationLock {
  release(): Promise<void>;
}
```

## Responsibilities (ADR-0006)

- **Concurrency is adapter-owned** (R3) : PostgreSQL advisory lock
  (distributed), SQLite Node `BEGIN EXCLUSIVE` (process-safe), SQLite
  navigateur single-writer (runtime-safe only, documented limit).
- **SQL is never generated by the adapter** : it is produced by the Grammar and
  executed through this port (R2).
- The engine (`@mosaix/migrations`) depends only on this port.

## Adapters

- Planned : `@mosaix/adapter-database-postgres` — advisory locks.
- Planned : `@mosaix/adapter-database-sqlite-node` — `better-sqlite3` / `node:sqlite`.
- Planned : `@mosaix/adapter-database-sqlite-wasm` — `sql.js` / OPFS single-writer.
